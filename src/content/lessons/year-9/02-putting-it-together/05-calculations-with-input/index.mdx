## The big idea

Almost every program follows the same three steps, like a recipe:

1. **Input**: read the numbers. Use `int.Parse(Console.ReadLine())` so they are numbers, not text.
2. **Process**: do the sum and keep the answer in a new variable.
3. **Output**: print the answer.

```csharp
int age = int.Parse(Console.ReadLine());            // 1. input
int futureAge = age + 5;                            // 2. process
Console.WriteLine("In five years: " + futureAge);   // 3. output
```

Read `int.Parse(Console.ReadLine())` from the **inside out**: `Console.ReadLine()` collects the text, `int.Parse()` turns it into a number, and `=` puts it in the `int` box.

<InputFlow typed="12" />

<Note title="Maths order">
C# does `*` and `/` before `+` and `-`. So `2 * 8 + 3 * 5` is `16 + 15`, which is `31`.
</Note>

## Whole numbers and decimals

Here is a C# surprise. When **both** numbers are ints, `/` gives a whole-number answer and throws the remainder away.
So `7 / 2` is `3`, not 3.5. This is called **integer division**.

If one of the numbers has a decimal point, C# keeps the decimal part: `7 / 2.0` is `3.5`.

<CsChecker task="share-sweets" predict="You have 7 sweets to share between 2 friends. If you type 7, what two lines will it print?" />

<Note title="Reading a decimal">
For numbers that can have a decimal point, such as a price, use a `double` box and `double.Parse()`:

```csharp
double price = double.Parse(Console.ReadLine());
Console.WriteLine(price * 2);
```

If the user types 1.25, this prints 2.5. A double that comes out whole, like 5.0, prints as just `5`.
</Note>
