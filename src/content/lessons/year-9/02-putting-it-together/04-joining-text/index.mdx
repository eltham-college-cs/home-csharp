## The big idea

There are two ways to build a sentence out of text and variables.

**A plus is superglue.** `+` sticks pieces together with **no** space. You type every space yourself, inside the speech marks.

**A dollar sign makes a fill-in-the-blanks sentence.** Put `$` just before the speech marks, then write the whole sentence with each variable in curly braces, like `{name}`. C# fills in each gap with what's inside the box. This is called **string interpolation**.

```csharp
string name = "Sam";
int age = 12;
Console.WriteLine("Hi " + name + " you are " + age);   // Hi Sam you are 12
Console.WriteLine($"Hi {name} you are {age}");         // Hi Sam you are 12
```

Both lines print the same thing. Both are happy to mix text and numbers: C# turns `age` into text for you.

<Note title="Joining is called concatenation">
`"Hi" + "Sam"` gives `HiSam`. No space is added. Put the space inside the speech marks: `"Hi " + "Sam"`.
</Note>

<Note title="Don't forget the $">
Without the `$`, the braces are just ordinary text: `Console.WriteLine("Hi {name}");` prints `Hi {name}`, braces and all.
</Note>

<Note title="Sums inside a sentence">
C# works through `+` from left to right. In `"Total: " + 3 + 4`, it first makes the text `"Total: 3"`, then glues `4` on the end: `Total: 34`!
Put brackets round the sum, `"Total: " + (3 + 4)`, or use the braces: `$"Total: {3 + 4}"`. Both print `Total: 7`.
</Note>
