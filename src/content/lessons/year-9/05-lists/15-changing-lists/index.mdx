<ParentTip>
You don't need to know C#. Use paper slips for the list. Add means "put a slip on the end". Insert means "squeeze a slip in". Remove means "take a slip away and close the gap". Overwrite means "rub one out and write a new word".
</ParentTip>

## The big idea

A list is not fixed once you have made it. You can tell it to change:

```csharp
List<int> scores = new List<int> { 12, 19, 7 };
scores.Add(25);         // add 25 to the end:     12, 19, 7, 25
scores[0] = 20;         // overwrite item 0:      20, 19, 7, 25
scores.Insert(1, 5);    // put 5 in at index 1:   20, 5, 19, 7, 25
scores.Remove(7);       // remove the value 7:    20, 5, 19, 25
scores.RemoveAt(0);     // remove item 0:         5, 19, 25
Console.WriteLine(scores.Contains(19));   // True
Console.WriteLine(scores.Count);          // 3
```

Read `scores.Add(25);` aloud as "scores, add 25": the list is being told to do something.
When you insert or remove, the items after it shuffle along, so their indexes change.

`.Contains(…)` asks a true or false question: "is this value in the list?" C# prints the answer as `True` or `False`, with a capital letter.

Last lesson you met `string.Join`. It's the quickest way to see the whole list: `Console.WriteLine(string.Join(", ", scores));` prints `5, 19, 25`.

<Note title="Remove or RemoveAt?">
`Remove` is told a **value**: `scores.Remove(7)` finds the first 7 and takes it out. `RemoveAt` is told an **index**: `scores.RemoveAt(0)` takes out item 0, whatever it is. In a `List<int>` both take a number, so C# can't tell you if you picked the wrong one.
</Note>

## Swap the ends
