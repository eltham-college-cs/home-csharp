## The big idea

If you catch yourself writing `score1`, `score2`, `score3`… you want a **list**: one variable that stores several values, in order.

```csharp
List<int> scores = new List<int> { 12, 19, 7, 25, 16 };
```

Read it from the left:

- `List<int>` is the type: "a list of ints". A list holds **one type** of thing, and that type goes in the angle brackets `< >`. A list of names is a `List<string>`. You can't put `"hello"` into a `List<int>`: C# won't build the program.
- `new List<int> { … }` makes the list, with the starting items inside the curly braces and a comma between each one.

Text items need speech marks:

```csharp
List<string> names = new List<string> { "Ava", "Ben" };
```

Each item has an **index**: its position number. Computers count from **0**.

<MemoryBoxes list={{ name: "scores", items: ["12", "19", "7", "25", "16"] }} caption="Five items, so the last index is 4, not 5." />

```csharp
Console.WriteLine(scores[0]);     // 12
Console.WriteLine(scores[2]);     // 7
Console.WriteLine(scores[4]);     // 16
Console.WriteLine(scores.Count);  // 5, how many items
```

To visit every item in turn, use a **foreach** loop. Read it as "for each score in scores":

```csharp
foreach (int score in scores)
{
    Console.WriteLine(score);
}
```

Each time round the loop, `score` holds the next item: 12, then 19, then 7, and so on.

<Note title="You can't print a whole list">
`Console.WriteLine(scores);` does not show the items. It shows the list's type name, ``System.Collections.Generic.List`1[System.Int32]``, which is no use to anyone. Use a foreach loop, or `string.Join`, which joins every item into one piece of text with your choice of separator between them: `Console.WriteLine(string.Join(", ", scores));` prints `12, 19, 7, 25, 16`.
</Note>
