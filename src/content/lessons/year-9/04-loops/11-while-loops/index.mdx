## The big idea

A `for` loop asks **"how many?"** A `while` loop asks **"are we there yet?"**, and it asks again every single time round.

| | for | while |
|---|---|---|
| Proper name | count-controlled | condition-controlled |
| You know in advance | how many times | when to stop |
| It stops when | the count runs out | the condition becomes false |
| Good for | times tables, every letter in a word | passwords, menus, games |

Every while loop needs **three things**, or it breaks:

1. **Start value**: set the variable before the loop. `int count = 5;`
2. **Condition**: a true or false question about it, in round brackets. `while (count > 0)`
3. **Update**: change the variable inside the loop's curly braces, so the answer can become false. `count = count - 1;`

```csharp
int count = 5;
while (count > 0)
{
    Console.WriteLine(count);
    count = count - 1;
}
Console.WriteLine("Lift off!");
```

<Note title="No semicolon after the while line">
The `while (count > 0)` line is not a whole instruction on its own, so it has **no semicolon**. The lines that repeat go inside the `{` and `}` underneath it, just like an `if` or a `for` loop.
</Note>
