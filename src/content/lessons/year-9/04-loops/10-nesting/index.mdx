## The big idea

**Curly braces show what is inside what.** Every `{` opens a box, and its matching `}` closes it. A box can sit inside another box, like a set of Russian dolls. That's **nesting**.

```csharp
for (int x = 1; x <= 6; x++)
{
    if (x % 2 == 0)
    {
        Console.WriteLine(x + " even");
    }
}
```

The `Console.WriteLine` is inside the if's braces, which are inside the loop's braces.

- An **if inside a for** makes a fresh decision every time round.
- A **for inside a for** works like a car's mileage counter: the inner loop spins all the way round for every single click of the outer loop.

<Note title="Indentation is for humans">
The spaces at the start of each line don't change what C# does: only the braces do. We indent 4 spaces for each box so that **people** can see the boxes at a glance. If the indentation and the braces disagree, C# believes the braces.
</Note>
