## The big idea

Almost every while loop is one of five shapes. Notice that every condition names a variable the body is going to change.

| Shape | Condition looks like | Used for |
|---|---|---|
| Counter | `while (count > 0)` | countdowns |
| Retry | `while (attempt != password)` | logins |
| Retry with a limit | `while (attempt != password && tries < 3)` | three lives |
| Validation | `while (age < 11 \|\| age > 18)` | keeping bad input out |
| Sentinel | `while (choice != "q")` | menus, quitting |

`&&` means **and** (both must be true). `||` means **or** (at least one must be true). `!=` means **is not equal to**.

<Note title="Prime the loop">
The password loop reads input **twice**: once before the loop, so the condition has something to test, and once inside, as the update. Delete the one inside and the loop never ends.
</Note>

## Validation

<CsChecker task="age-check" brief="Keep asking until the age is between 11 and 18. Each time it is wrong, print <strong>Enter an age between 11 and 18.</strong> When it is right, print <strong>Thanks!</strong>" />

<Note title="What if they type a word?">
`int.Parse("twelve")` crashes with a FormatException. You don't need to handle that today, but here is how it's done, for later. `int.TryParse` *tries* to turn the text into a number. It gives back `true` if it worked (and puts the number in `age`), or `false` if it didn't, so it can go in a loop condition:

```csharp
int age;
while (!int.TryParse(Console.ReadLine(), out age))
{
    Console.WriteLine("Please type a number.");
}
```

`!` means **not**, so the loop keeps going while the text is *not* a number.
</Note>

## Extra challenge

<CsChecker task="menu" brief="Build a menu that loops until the user types <strong>q</strong>. <strong>p</strong> prints <strong>Starting game...</strong>, <strong>s</strong> prints <strong>High score: 42</strong>. After the loop, print <strong>Bye!</strong>" />

<Note title="Another way to stop">
`while (true)` loops forever on purpose, and `break;` jumps straight out of it. Some programmers write menus like this:

```csharp
while (true)
{
    string choice = Console.ReadLine();
    if (choice == "q")
    {
        break;
    }
    Console.WriteLine("You chose " + choice);
}
```

Both ways are fine. Make sure there is always a way out!
</Note>
