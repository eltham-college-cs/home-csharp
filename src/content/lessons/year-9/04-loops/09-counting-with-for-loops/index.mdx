## The big idea

A **for loop** is like a coach saying "run 3 laps". The coach counts the laps for you, and the **loop variable** holds the lap number each time round.

```csharp
for (int i = 1; i <= 3; i++)
{
    Console.WriteLine("Lap " + i);
}
```

The brackets hold **three parts**, separated by semicolons:

| Part | Code | Means |
|---|---|---|
| Start | `int i = 1` | make a box called i, and put 1 in it |
| Keep going while | `i <= 3` | checked before every lap: if it's false, the loop stops |
| Change each time | `i++` | after every lap, add 1 to i |

The lines inside the curly braces `{ }` are the ones that repeat.
`i++` means "add 1 to i". To hop by more than 1, write `i += 2` (add 2), and to count down, `i--` (take 1 away) or `i -= 2` (take 2 away).

| Code | Gives |
|---|---|
| `for (int i = 2; i < 6; i++)` | 2, 3, 4, 5 |
| `for (int i = 2; i <= 6; i++)` | 2, 3, 4, 5, 6 |
| `for (int i = 0; i <= 8; i += 2)` | 0, 2, 4, 6, 8 |
| `for (int i = 10; i >= 2; i -= 2)` | 10, 8, 6, 4, 2 |
| `for (int i = 5; i < 5; i++)` | nothing at all |

<Note title="Watch < and <=">
`i < 6` stops **before** 6. `i <= 6` includes 6. One little = makes the difference of a whole lap.
</Note>

<Note title="No semicolon after the brackets">
The for line has semicolons **inside** its brackets, but never one at the end. The `{ }` come straight after.
</Note>
