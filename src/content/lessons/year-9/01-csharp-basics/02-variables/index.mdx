## The big idea

A **variable** is like a labelled box in the computer's memory.

- The **label** is the variable's name.
- The box holds **one value** at a time.
- Put a new value in and the old one is thrown away.

In C#, every box also has a **type** written on the side. The type says what kind of value the box can hold:

- `string` for text, like `"Sam"`
- `int` for whole numbers, like `12`
- `double` for numbers with a decimal point, like `1.5`
- `bool` for `true` or `false`

```csharp
string name = "Sam";     // a string box called name
int age = 12;            // an int box called age
double height = 1.5;     // a double box called height
bool happy = true;       // a bool box called happy
```

The type and the name go on the **left** of `=`, and the value goes on the **right**. Read `=` as "is set to".

<Note title="Make the box once, then change what's in it">
The first time, you write the type: `int score = 10;`. This **declares** the box (makes it).
After that, leave the type off: `score = 20;` just puts a new value in the same box.
If you write `int score` a second time, C# complains that the box already exists.
</Note>

<Note title="A box only holds its own type">
An `int` box can only hold whole numbers. `int age = "12";` will not build, because `"12"` (with speech marks) is text.
C# checks this before your program runs, so you find out straight away.
</Note>

<Note title="Naming rules">
Use letters and numbers. No spaces: write `favouriteColour`, not `favourite colour`. Don't start with a number. Capitals matter: `Age` and `age` are different boxes. C# programmers start each new word with a capital, except the first.
</Note>
