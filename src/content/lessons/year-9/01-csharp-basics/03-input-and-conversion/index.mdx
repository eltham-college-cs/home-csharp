## The big idea

`Console.ReadLine()` is like a waiter taking your order. The program stops and waits until
you type an answer and press Enter. Whatever you type comes back as **text** (a `string`), even if it looks like a number.

`int.Parse()` is like a currency exchange: it swaps the text `"15"` for the number `15`,
so you can do sums with it.

<InputFlow typed="15" />

```csharp
string name = Console.ReadLine();             // text stays text
int age = int.Parse(Console.ReadLine());      // text swapped for a number
```

<Note title="Always store the answer in a box">
`string name = Console.ReadLine();` keeps the answer in the variable `name`. Without the `string name =` part, the answer is thrown away.
</Note>

<Note title="Text won't fit in a number box">
`int age = Console.ReadLine();` won't build. `Console.ReadLine()` gives text, and an `int` box only holds whole numbers.
C# spots this **before** the program runs. Wrap it in `int.Parse( )` and count the brackets: `int.Parse(Console.ReadLine())` ends with two.
</Note>
